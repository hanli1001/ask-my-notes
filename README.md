# <学习笔记>

## 解决什么问题：快速查找对应的笔记内容，例如想到某个知识点的一部分，可以直接通过那一部分，找到对应的知识笔记，例如当你想到一个知识点，但是记不住具体称呼，如果用grep就会找不到结果，但是rag可以模糊搜寻，并且定位到关键位置


## 给谁用：我是第一个用户，我每次在查找笔记的时候需要寻找很久，对于一个嫌麻烦的人来说，这是个令人头痛的问题，所以我想通过一个方式记录笔记的内容，然后可以通过模糊搜寻找到对应的知识


## 怎么算做成功了：模糊搜寻可以找到我想要的被记录的笔记，就是与我的目标匹配度一致，且标注正确的真实的文件的位置，如果失败没查寻到应该返回（未查到对应的笔记内容）
